What the frames show

Existing (unchanged)

  • Page head, «Обновлено N назад», «Сохранить себе» (the primary action stays first, rule 9), list notes, rows, row notes, the selection bar.
  • The filter strip and panel are FilterBar.svelte as the tables draw it: the «Фильтры» toggle with a caret, pills with ×, «Сбросить всё», the «N из M» count, rows labelled with «любое» while nothing is picked.
  • The search box is SearchBox.svelte with the tables' placeholder; the empty result is Empty.svelte with «Ничего не найдено» and «Сбросить всё», as on a table.

Proposed NEW

  • Placement: one block between the list notes and «Выбрать все»: the search box, then the filter strip. The block opens from 8 drawn entries (LIST_SEARCH_AT, the threshold of the lists index's name filter) or with a filter or query already set, and once open it stays until another list opens. Inside it the strip is drawn only while at least one row can narrow (cases 1-3).
  • Dynamic facets: the groups and values come from the entries this reader's page draws, nothing else. A value no entry answers is not offered; a row is drawn only when one of its values can narrow the list. On the seed list the panel offers Type (4 values), Source (6), Tier (2), Class, Trait, Range, Burden and Line; no «Вторичное», no «Очень далеко», no Tier 3/4.
  • Type row: «Предметы», «Расходники», «Оружие», «Вторичное», «Броня» - the search page's two kind words and the equipment tables' three tab words, because a list mixes gear that the tables split by table.
  • In the address, as on a table (owner, 2026-10-06): a pick writes #/s/<token>/f_<filter> with replaceState, in the tables' grammar (f_kind-weapon.tier-1). While a value is picked, the strip draws the copy-link button; it copies <site>#/s/... in Russian and <site>en/#/s/... in English and toasts «Ссылка на фильтры скопирована». On a GM link the toast warns that the copy is the GM's link. A filter link that arrives opens the panel, as on a table. A build before this one reads the token and ignores the segment: the whole list, never an error.
  • A value the list does not hold (an old link, or the owner sold the last armour) draws no pill and narrows nothing; the next change of the filter writes only the values in force. This departs from a table, where such a value empties the table.
  • #/l/ links (state 6): the payload is read as written, so the address cannot carry a segment there. The filter works as page memory and the strip draws no copy-link button; the address stays as it opened. The route retires on 2026-10-26.
  • Ticks survive filtering: in state 3 «Первоклассный Спальный Мешок» stays ticked although the filter hides it; the bar counts it («Выбрано 2 позиции»). «Выбрать все (3)» ticks the drawn rows only, as on a table.
  • Long pill (campsite fix): a pill now wraps inside the strip, so an 80-character own-source name never scrolls the page sideways at 360 px (rule 16). Normal pills draw as today.

Not drawn on purpose

  • No counts on chips (the "Alt" state shows them for comparison): the table filter has none, and a count would add a second chip shape to one shared component.
  • No narrowing of one row by the picks in another: facetRows states that a facet offers values and does not narrow itself.
  • GM-only entries (TASK 70): a players' link never receives them, so they can never appear as a value or in a count there; a filter link that names such a value on a players' link draws nothing for it.
