TASK 70 - GM-only entries in an account list

Revision 2, after the owner's answers of 2026-10-06 (Q1-Q4 and the mock feedback, section 9). Mockups for the owner's review. Issue 70: the list owner hides chosen entries from players; the change reaches open pages through Realtime. Every frame below is built from the app's own tokens and component CSS (HEAD d997f4f0); new marks the proposal, everything else is today's app.

The state reuses the name and the icon the app already gives to a GM note: «Только для мастера» / "GM only" with the crossed eye. A GM-only entry is shown to the owner and on the GM's link, and it is absent from the players' link - the server drops it from what a players' link reads, so it never reaches a player's browser.

1. The owner's list page, 1180 px, RU approved direction

  • 1new The count of GM-only entries in the sub, between the entry count and the save status, only while there is one: «только для мастера: 2».
  • 2new A third button in the row's action column, between «Заметка» and «Убрать из списка»: the eye. Its name is «Только для мастера: <item>» with aria-pressed. Pressed, it shows the crossed eye in gold on the note button's own "on" ground.
  • 3new A GM-only row: dashed border (DESIGN.md: a dashed border marks a property), the recessed --bg2 ground and the art at 45%. No text marker on screen: the pressed eye and the row look carry the state (owner, 2026-10-06). For a screen reader the item's button names the state in visually hidden text («Кольцо Тишины, Только для мастера»). Quantity, price, notes, drag and remove work as on any row.
  • iRow 4 also has an example GM note («Под прилавком: ...»), opened by its note button. It is ordinary note text, not a marker of the state; a GM-only row may have no note at all, as row 6.

4. The players' link #/s/<token> - the entries are absent

Nothing on the page says that something is hidden: the count, the rows, the roll numbers and the selection bar know only what the server sent. A GM-only entry that a player has ticked leaves the selection on the next read (today's rule for an entry the list no longer holds), and the hidden status «Список обновлён» is said as for any change the link shows. TASK 71's filters see only these rows, so no facet or count can reveal a GM-only entry.

"Delete link" ends access: a deleted link no longer opens the list. "Create link" makes a new one. The players' link hides the "GM only" notes and items; the GM's link shows them - give it to GMs only.

7. Alternatives

rejected A badge only, no row restyle

A dashed gold badge «Только для мастера» joins the kind and source badges; the row keeps its normal border and art. Quieter, and it moves to the second line at 360 px, where it is easy to miss in a long list. Rejected: the owner asked for no text marker; the row look and the eye carry the state.

alternative B - owner - RU
4Кольцо ТишиныПотратьте Надежду, чтобы активировать это кольцо.Только для мастераПредметCore

rejected

  • A separate «Скрытые» group at the end of the list. It breaks the owner's order, the roll numbers and the position field.
  • A labelled checkbox «Видно игрокам» in the quantity and price box. It costs about 80 px of every row at 360 px for a control most rows never use.
  • Hiding in the players' browser only (CSS or a client filter). The entry would still reach the player in the link's answer. The context's constraint and the issue forbid it.

9. The owner's answers (2026-10-06)

  1. Q1 - the GM's link shows GM-only entries, marked: yes (section 5).
  2. Q2 - the name: «Только для мастера» / "GM only". The selection bar's verbs stay «Скрыть от игроков» / «Показать игрокам».
  3. Q3 - the lists file keeps the mark: yes, as import-v3: a list entry may carry "gm_only": true; the export writes version 3 only when a list holds a GM-only entry, so every file without one stays import-v1 or import-v2 byte for byte; the import reads versions 1-3. No screen change.
  4. Q4 - the selection-bar action with undo: yes (section 3).
  5. Mock feedback: no flag line under the name on any page; the example GM note is only a note; the counts are absent while N = 0; the share hint says that the players' link hides both the GM notes and the GM-only items (section 6 and the strings table).
