Файл JSON, сохранённый кнопкой «Экспорт» или собранный по схеме import-v1. Списки добавятся как новые; существующие не изменятся.

«Выбрать файл...» is a `Button`-styled label over a visually hidden `<input type="file" accept=".json,application/json">`. The preview is drawn from the pure validator (`lib/bundle.ts`) before anything is sent: counts, the unknown ids (skipped, never refused - the `#/l/` rule) and the duplicates dropped. «Импортировать (N)» sends one `import_lists` call; on success the panel folds, the new lists go first in the group with «изменён только что» and the toast reads «Импортировано списков: 2». A limit refusal is the existing limit toast; no network is «Не получилось. Попробуйте ещё раз.» and the preview stays.

The first ten errors, each with its JSON path, then «...и ещё N». One-line refusals take the same box with one line: not JSON, not a lists file (no `format`), an unknown `version`, no lists, a file over 5 MB. Nothing is imported from a refused file; the preview and the button are not drawn.
