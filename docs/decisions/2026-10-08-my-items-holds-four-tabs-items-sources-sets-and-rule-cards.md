# 2026-10-08 - «Мои предметы» holds four tabs: items, sources, sets and rule cards

- Task: `persist-7h-homebrew-page` (owner, 2026-10-03, W3: one page per kind, one import; planner, the routes and the tab row).
- Decision: «Мои предметы» draws one head (the heading, the lead, «Импорт из файла») and a tab row of four links, «Предметы», «Источники», «Комплекты», «Карты правил», at `#/homebrew`, `#/homebrew/sources`, `#/homebrew/sets[/<key>]` and `#/homebrew/rules[/<key>]` (a key opens and scrolls to that card's fold). The route is one kind, `homebrew`, with a tab and a key. The «Источники» and «Карты» folds of the Items page become the Sources, Sets and Rules tabs; the Sets and Rules tabs add and remove an item's set or rule card from the card itself, as an update of the item. One import and one account export stay; a tab press keeps the import panel and the Items tab's ticks.

- Accepted trade-off: rule 9's departure (the import sits above the tab row, and each tab's create button is the first control under it); the source and card counts move to their tabs; a source name typed on the Sources tab is lost on a tab press with no question; the frame's selection bar can count Items-tab ticks while another tab is drawn.
