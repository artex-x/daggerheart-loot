# 2026-11-11 - No rule card for core conditions; each record keeps its definition

- Task: `errata-audit` (owner, 2026-11-11, option A of O5).
- Decision: the catalog adds no rule or reference card for conditions. A custom condition is
  defined on the record that uses it; a core condition (Vulnerable, Restrained, Hidden) is not
  defined in the catalog.
- Rejected: one "Core conditions" card linked from every record that uses them (a new data and
  golden batch, and the print card and the share stub show no card text); per-source condition
  cards (they repeat what each record already says).
- Evidence: the same condition name carries different rules in different books (Stunned four
  times, On Fire three times, Incorporeal twice), so a shared card would merge rules that differ.
- Trade-off: a reader looks up Vulnerable, Restrained and Hidden elsewhere.
