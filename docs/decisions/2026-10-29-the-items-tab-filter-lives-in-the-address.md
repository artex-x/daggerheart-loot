# 2026-10-29 - The Items tab filter lives in the address

- Task: `catalog-filter-links` (owner, 2026-10-28, Q2 = A).
- Decision: the picked values of the Items tab filter of «Мои предметы» are the address `#/homebrew/f_<filter>` (path `/homebrew/f_<filter>`, `/en/...` in English), with the `homebrew` groups `kind`, `src` and `sect`; on this tab `src` is a facet, its values OR'd. A pick, a pill drop or a reset rewrites the address in place (`replaceState`); nothing else writes it. The panel's fold, the query and the strip's latch are page memory; the panel opens when the page reads a filter it did not write (a filter address, Back, a reload, a press on «Предметы»), as on the tables and shared pages. A value no row offers draws no pill and narrows nothing; the next pick writes only the values in force. Homes: `docs/specs/ROUTES.md`, "Homebrew" and "Filter grammar"; `STATE.md`, "Filters" and "Homebrew"; `FEATURES.md`, "Homebrew", the Items tab and rule 17; `CONTRACTS.md` section 1.
- Rejected: B, the open state in the address too (a marker such as `/open` after the segment: a grammar shape on one page only); page memory as before (Back from the editor and a reload lose the filter).
- Accepted trade-off: Back from the editor and a reload open the panel even if the person had folded it; the pills show the filter either way. An earlier build reads the address as unreadable and opens the home section; nothing is stored, so nothing is lost.
