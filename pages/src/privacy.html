Конфиденциальность

Здесь написано, что хранит генератор лута Daggerheart, где это лежит и как это удалить. Сайт - личный проект, его ведёт artex-x.

Что сайт хранит сейчас

  • Если вы не входите в аккаунт, на сервере о вас не хранится ничего. На сайте нет cookie, аналитики и рекламы, и он ничего не загружает с сайтов других компаний.
  • Ваши списки, язык и другие настройки лежат в локальном хранилище браузера на вашем устройстве. Чтобы их удалить, очистите данные сайта в браузере.
  • Ссылка на список несёт сам список после знака #. Эту часть адреса браузер не отправляет на сервер, поэтому список видят только те, у кого есть ссылка.
  • Сайт размещён на GitHub Pages. GitHub получает обычные технические данные каждого запроса, например IP-адрес; их описывает заявление GitHub о конфиденциальности.

Если вы войдёте в аккаунт

Войти можно через Google или Discord, и тогда сайт хранит:

  • ваши списки, ваши собственные предметы, их картинки и ваши настройки;
  • учётную запись Google или Discord, которую провайдер передаёт при входе, и ваш адрес электронной почты. Их хранит Supabase Auth; почту сайт показывает только вам.

Эти данные Supabase хранит в регионе EU West (Ирландия). Никому другому они не продаются и не передаются.

Ссылки для доступа

Ссылка для доступа к списку бывает для игроков и для мастера. Любой, у кого есть ссылка, может открыть этот список в виде для игроков или для мастера, пока вы не замените ссылку новой или не отзовёте её. Вид для игроков не показывает заметки мастера. Сама ссылка хранится вместе со списком, прочитать её там можете только вы, поэтому её можно скопировать снова в любой момент. Ссылка на собственный предмет работает так же. Ваше имя и почту ссылка не показывает никогда.

Удаление данных

Если вы вошли в аккаунт, удалить его можно на странице аккаунта. Удаление происходит сразу: списки, собственные предметы, картинки, настройки и ссылки для доступа сразу уходят из рабочей базы, и все ссылки перестают открываться. Резервная копия, сделанная до удаления, может хранить эти данные, пока её не заменит новая.

Если Google или Discord уже занят

Аккаунт Google или Discord может принадлежать только одному аккаунту на сайте. Если подключить тот, которым уже пользуется другой ваш аккаунт, сайт откажет. Чтобы объединить их, войдите в аккаунт, от которого хотите отказаться, выгрузите его данные и удалите его. Затем войдите в аккаунт, который оставляете, загрузите данные и снова подключите Google или Discord.
