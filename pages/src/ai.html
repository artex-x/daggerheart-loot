С ИИ-ассистентами

Эта страница рассказывает, как дать ИИ-ассистенту работать с генератором лута Daggerheart: что у него можно попросить, как его подключить и что он может и чего не может. Если вы пишете программы, читайте вместо неё страницу для разработчиков.

Что можно попросить

  • Бросить кубики на любой таблице лута сайта, с показанными кубиками.
  • Найти предмет по части названия, по-русски или по-английски, или по виду, источнику, тиру и редкости.
  • Прочитать полный текст предмета, его характеристики и строку крафта.
  • Проверить файл списков или файл своих предметов до импорта: с теми же ошибками, что покажет импорт.
  • Прочитать общий список или общий предмет по его ссылке.
  • Позже: ваши списки и предметы. Ассистент получит этот доступ только после вашего разрешения на странице аккаунта, и вы сможете отозвать его там же.

Подключение в три шага

Все ассистенты ниже берут один и тот же адрес и не требуют ни входа, ни ключа:

https://daggerheart-loot.pages.dev/mcp

Шаги записаны так, как их даёт справка каждого ассистента на 13 ноября 2026 года. Если пункт меню у вас называется иначе, верна справка.

Claude (claude.ai)

  1. Откройте Customize, затем Connectors.
  2. Нажмите «+ Add», затем «Add custom connector». Введите название и адрес выше и нажмите «Continue».
  3. В поле Authentication выберите «No sign in» и нажмите «Add».

Свои коннекторы работают на тарифах Free (один коннектор), Pro, Max, Team и Enterprise; на Team и Enterprise коннектор сначала добавляет владелец организации. Справка Claude даёт шаги только для claude.ai.

Cursor

  1. Откройте Customize в боковой панели или файл ~/.cursor/mcp.json (для всех проектов) или .cursor/mcp.json (для одного проекта).
  2. Добавьте сервер с его адресом:
  3. Сохраните файл.
{
  "mcpServers": {
    "daggerheart-loot": {
      "url": "https://daggerheart-loot.pages.dev/mcp"
    }
  }
}

См. страницу MCP в документации Cursor.

Claude Code

  1. Выполните в терминале команду:
claude mcp add --transport http daggerheart-loot https://daggerheart-loot.pages.dev/mcp
  1. Выполните claude mcp list. Сервер показан как подключённый.
  2. Внутри Claude Code тот же статус показывает /mcp.

Добавьте --scope user, чтобы сервер работал во всех ваших проектах. См. страницу MCP в документации Claude Code.

Другой ассистент

Ассистент, который позволяет добавить удалённый MCP-сервер по адресу без входа, берёт адрес выше так же. Для ChatGPT здесь нет шагов: сегодня его справка не говорит, что он принимает сервер без входа.

Что он может и чего не может

  • Подключение только читает. Ассистент не меняет ни ваши списки, ни ваши предметы.
  • Для общедоступных данных (каталог, таблицы, броски, общая ссылка) аккаунт не нужен.
  • Доступ к вашим спискам и предметам запланирован. Для него понадобится ваше явное разрешение, и вы сможете его отозвать.
  • Импортировать файл за вас ассистент не может. Чтобы создать список или предметы, попросите у него файл и импортируйте его на странице «Списки» или в «Мои предметы» (в панели импорта есть ссылка на эту страницу).

Конфиденциальность и честное использование

Компания ассистента получает то, что ассистент спрашивает у сайта, и ответы сайта. Сайт ничего не хранит об этих вызовах и не ставит куки; Cloudflare, где размещён сайт, получает обычные технические данные каждого запроса. Все запросы делят один суточный лимит со всем сайтом, поэтому просите то, что нужно, и не больше. Подробности на странице о конфиденциальности.

Примеры запросов

  • «Брось три кубика на таблице лута и скажи, что мне выпало.»
  • «Найди оружие 2 тира со словом "топор" в названии.»
  • «Прочитай мне полный текст предмета ci12 и дай ссылку на него.»
  • «Проверь этот файл списков до импорта» (и вставьте файл).
  • «Собери файл списка из пяти лечебных расходников каталога и скажи, как его импортировать.»
