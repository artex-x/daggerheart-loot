API для разработчиков

Эта страница описывает открытый API чтения генератора лута Daggerheart: как его вызывать, что он возвращает и чего он ждёт от клиента. Полное машинное описание - openapi.json (OpenAPI 3.1); то же описание в читалке - вид Redoc.

Базовый адрес, ключи и CORS

  • Базовый адрес: https://daggerheart-loot.pages.dev/api/v1/. Каждый ответ - JSON.
  • Ни ключа, ни входа. API игнорирует заголовок Authorization, поэтому ответ не зависит от того, кто спрашивает.
  • Каждый ответ несёт Access-Control-Allow-Origin: * и никаких учётных данных, так что инструмент в браузере может вызывать API напрямую. Запрос OPTIONS получает 204.
  • API только читает. Списки и свои предметы меняются только в приложении.

Честное использование и квота

Кэшируйте списки (броски, таблицы, каталог) и отправляйте не больше одного запроса на действие пользователя. Все запросы Functions сайта, API и карточки ссылок вместе, делят одну суточную квоту в 100 000. Когда всплеск её исчерпывает, API и карточки ссылок отвечают ошибкой до 00:00 UTC; приложение продолжает работать. Чтобы прочитать весь каталог без запросов к квоте, используйте статическое зеркало ниже.

Заморозка v1

Пути, имена параметров, имена полей и значения format в v1 не меняются. Новый необязательный параметр, новое поле или новый ресурс могут появиться в v1, поэтому клиент игнорирует незнакомые поля. Несовместимое изменение - это /api/v2/ рядом с v1. Клиент, который встретил незнакомый code ошибки, ориентируется на HTTP-статус.

Запись и её права

Запись - это daggerheart-loot/record версии 1: id, key, origin, kind, name, text (подмножество Markdown) и plain (простой текст), path, link, source, table, roll, tier, rarity, stats, craft, set, refs, image и rights. Каждый текст для человека - пара { "ru", "en" }; пустая русская сторона повторяет английский текст. Храните link как есть: его ?v непрозрачен.

rights.license равно dpcgl, где английский текст - общедоступное игровое содержимое Daggerheart SRD 2.0, и owner, где им владеют правообладатели; русский текст - перевод, которого dpcgl не покрывает. rights.notice - английское уведомление, которое нужно показывать с текстом. Текст своих предметов и заметки списков пишут пользователи: экранируйте их перед показом.

Операции

Все операции openapi.json, у каждой есть запрос, который можно выполнить.

GET /api/v1/openapi.json

Читает описание API.

curl https://daggerheart-loot.pages.dev/api/v1/openapi.json

GET /api/v1/rolls

Перечисляет разделы бросков с их режимом, частями и пределами. Меняется только с выкладкой данных. 

curl https://daggerheart-loot.pages.dev/api/v1/rolls

POST /api/v1/rolls/{section}

Бросает раздел или разбирает введённое число и отвечает не больше чем четырьмя записями в порядке, в котором их достаёт приложение. Тело - JSON; его поля зависят от режима раздела. 

curl -X POST -H 'Content-Type: application/json' -d '{"dice":3}' \
  https://daggerheart-loot.pages.dev/api/v1/rolls/std

GET /api/v1/tables

Перечисляет таблицы каталога.

curl https://daggerheart-loot.pages.dev/api/v1/tables

GET /api/v1/tables/{table}

Читает строки одной таблицы. Три таблицы снаряжения читаются по тиру через part. filter принимает сегмент фильтра страницы таблиц, например f_burden-2, и оставляет те строки, что оставляет страница. 

curl 'https://daggerheart-loot.pages.dev/api/v1/tables/eq_weapon?part=2&filter=f_burden-2'

GET /api/v1/records

Ищет по каталогу по названию, по-русски или по-английски, и по kind, source, table, tier и rarity. Передайте q или фильтр; limit - от 1 до 50. Поиск идёт только по названиям. Слово, под которое попадает слишком много записей, получает 400 too_broad: добавьте слово подлиннее или фильтр. 

curl 'https://daggerheart-loot.pages.dev/api/v1/records?q=sword&kind=weapon'

GET /api/v1/records/{id}

Читает одну запись каталога.

curl https://daggerheart-loot.pages.dev/api/v1/records/ci12

GET /api/v1/homebrew-items/{uuid}

Читает один свой предмет, ссылкой на который поделился автор.

curl https://daggerheart-loot.pages.dev/api/v1/homebrew-items/00000000-0000-4000-8000-000000000000

GET /api/v1/shared-lists/{token}

Читает список за общей ссылкой так, как его видит аудитория ссылки. Список, чей ответ базы больше 65536 байт, получает 422 со ссылкой на приложение. 

curl https://daggerheart-loot.pages.dev/api/v1/shared-lists/SHARE_TOKEN_OF_43_CHARACTERS

POST /api/v1/file-checks

Проверяет текст файла списков или файла своих предметов так, как проверил бы импорт приложения, и отвечает его ошибками и пропусками на двух языках. Тело - сам файл, JSON, не больше 32768 байт. Ничего не меняет. 

curl -X POST -H 'Content-Type: application/json' --data-binary @lists.json \
  https://daggerheart-loot.pages.dev/api/v1/file-checks

Ошибки

Ответ с ошибкой - { "format": "daggerheart-loot/api-error", "version": 1, "error": { "code", "message" } }. Сообщение английское и не повторяет значений.

Статус Код Когда
400 bad_request Параметр или поле тела не проходит схему, или параметр передан дважды.
400 too_broad Под поиск попадает слишком много записей для ранжирования.
404 not_found Неизвестный путь, раздел, таблица, запись, id предмета или токен ссылки.
405 method_not_allowed Другой метод; заголовок Allow называет разрешённые.
413 too_large Тело больше 4096 байт или файл для проверки больше 32768 байт.
415 unsupported_media_type Тело POST не application/json.
422 answer_too_large Ответ базы больше 65536 байт.
503 unavailable Чтение не удалось, не уложилось по времени или оказалось неверным.

Кэширование

Списки и проекции несут ETag и Cache-Control: public, max-age=300 и отвечают 304 на совпавший If-None-Match. Броски, свои предметы, общие списки и проверки файлов - no-store.

Статическое зеркало каталога

https://daggerheart-loot.pages.dev/api/v1/catalog/index.json перечисляет каждую запись как { id, rev, chunk } с абсолютными адресами файлов-чанков. Файлы статические и не тратят запросов Functions.

  1. Прочитайте индекс. Если его data_version равен вашему, остановитесь.
  2. Прочитайте чанк каждой записи, чей rev отличается от вашего. rev непрозрачен: сравнивайте его только на равенство.
  3. Удалите каждый id, которого в индексе больше нет.
  4. Если у чанка другой data_version или чанк отвечает 404, сайт обновился между вашими чтениями: прочитайте индекс заново.

Имена и число чанков не заморожены: идите за индексом.

Ассистенты и MCP

llms.txt - вход для ассистентов; там же лежат форматы файлов импорта. Операции выше также являются инструментами MCP-сервера только для чтения по адресу https://daggerheart-loot.pages.dev/mcp; как его подключить, показано на странице для пользователей.

Чтение аккаунта

Чтение собственных списков и предметов вошедшего пользователя запланировано. В v1 сегодня его нет.
