With AI assistants

This page tells you how to let an AI assistant use the Daggerheart Loot Generator: what you can ask it, how to connect it, and what it can and cannot do. If you build software, read the page for developers instead.

What you can ask

  • Roll loot on any roll table of the site, with the dice shown.
  • Find an item by a part of its name, in Russian or in English, or by its kind, source, tier or rarity.
  • Read an item's full text, stats and crafting line.
  • Check a list file or a homebrew file before you import it, with the same errors the import shows.
  • Read a shared list or a shared homebrew item by its link.
  • Later: your own lists and items. The assistant will get that access only after you grant it on the account page, and you will be able to revoke it there.

Connect it in three steps

Every assistant below takes the same address and needs no sign-in and no key:

https://daggerheart-loot.pages.dev/mcp

The steps are as each assistant's own help page gives them on 13 November 2026. If a menu has another name in your version, the help page is the source.

Claude (claude.ai and Claude Desktop)

  1. Open Customize, then Connectors.
  2. Press "+ Add", then "Add custom connector". Enter a name and the address above, and press "Continue".
  3. Press "Continue" on the detected settings. Under Authentication choose "No sign in", then press "Add".

Custom connectors work on the Free (one connector), Pro, Max, Ultra, Team and Enterprise plans; on Team and Enterprise an organization owner adds the connector first. To use the connector, switch it on in a chat with "+", then "Connectors". See the help page of Claude.

Cursor

  1. Open Customize in the sidebar, or open the file ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project).
  2. Add the server with its address:
  3. Save the file.
{
  "mcpServers": {
    "daggerheart-loot": {
      "url": "https://daggerheart-loot.pages.dev/mcp"
    }
  }
}

See the MCP page of the Cursor documentation.

Claude Code

  1. Run this command in a terminal:
claude mcp add --transport http daggerheart-loot https://daggerheart-loot.pages.dev/mcp
  1. Run claude mcp list. The server shows as connected.
  2. Inside Claude Code, /mcp shows the same status.

Add --scope user to use the server in all your projects. See the MCP page of the Claude Code documentation.

Another assistant

An assistant that lets you add a remote MCP server by its address, with no sign-in, takes the address above in the same way. This page has no steps for ChatGPT yet.

What it can and cannot do

  • The connection only reads. The assistant changes none of your lists and none of your items.
  • For the public data (the catalog, the tables, the rolls, a shared link) you need no account.
  • Access to your own lists and items is planned. It will need your explicit grant, and you will be able to revoke it.
  • The assistant cannot import a file for you. To create a list or items, ask it for a file, then import that file on the Lists page or on "My items" (the import panel there has a link to this page).

Privacy and fair use

The assistant's company receives what the assistant asks the site for and what the site answers. The site stores nothing about these calls and sets no cookie; Cloudflare, which hosts the site, receives the usual technical data of each request. Every request shares one daily limit with the API and the link previews of the site, so ask for what you need and not more. The privacy page has the details.

Example prompts

  • "Roll three dice on the loot table and tell me what I found."
  • "Find the weapons of tier 2 that have the word 'axe' in the name."
  • "Read me the full text of the item ci12 and give me its link."
  • "Check this list file before I import it" (and paste the file).
  • "Read https://daggerheart-loot.pages.dev/llms.txt, then build me a list file with five healing consumables from the catalog and tell me how to import it."

The file for assistants

Assistants read llms.txt: it tells them how to use the site, and it also holds the formats of the files that you import.
