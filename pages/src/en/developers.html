API for developers

This page describes the public read API of the Daggerheart Loot Generator: how to call it, what it returns and what it expects of a client. The full machine description is openapi.json (OpenAPI 3.1); the same description in a reader is the Redoc view.

Base URL, keys and CORS

  • Base URL: https://daggerheart-loot.pages.dev/api/v1/. Every answer is JSON.
  • No key and no sign-in. The API ignores an Authorization header, so an answer never depends on the caller.
  • Every answer carries Access-Control-Allow-Origin: * and no credentials, so a browser tool can call the API directly. An OPTIONS request answers 204.
  • The API is read-only. Lists and homebrew items change only in the app.

Fair use and the quota

Cache the lists (rolls, tables, the catalog) and send at most one request for each user action. The API, the MCP endpoint and the link cards share one daily quota of 100,000 Functions requests. When a burst uses it up, the API and the link cards answer an error until 00:00 UTC; the app keeps working. To read the whole catalog without any request to the quota, use the static mirror below.

The v1 freeze

The paths, the parameter names, the field names and the format values of v1 do not change. A new optional parameter, a new field or a new resource may appear in v1, so a client ignores unknown fields. A break is /api/v2/ beside v1. A client that meets an error code it does not know acts on the HTTP status.

The record and its rights

A record is daggerheart-loot/record version 1: id, key, origin, kind, name, text (a Markdown subset) and plain (plain text), path, link, source, table, roll, tier, rarity, stats, craft, set, refs, image and rights. Every text a person reads is a pair { "ru", "en" }; an empty Russian side repeats the English text. Store link as given: its ?v is opaque.

rights.license is dpcgl where the English text is Daggerheart SRD 2.0 Public Game Content, and owner where its rights holders keep it; the Russian text is a translation that dpcgl does not cover. rights.notice is the English notice to show with the text. Homebrew text and list notes are written by users: escape them before you show them.

Operations

Every operation of openapi.json, each with an example request.

GET /api/v1/openapi.json

Reads the description of the API.

curl https://daggerheart-loot.pages.dev/api/v1/openapi.json

GET /api/v1/rolls

Lists the roll sections with their mode, parts and limits. It changes only with a data deploy. 

curl https://daggerheart-loot.pages.dev/api/v1/rolls

POST /api/v1/rolls/{section}

Rolls a section, or resolves a number you type, and answers up to four records in the order the app draws them. The body is JSON; its fields depend on the section's mode. 

curl -X POST -H 'Content-Type: application/json' -d '{"dice":3}' \
  https://daggerheart-loot.pages.dev/api/v1/rolls/std

GET /api/v1/tables

Lists the catalog tables.

curl https://daggerheart-loot.pages.dev/api/v1/tables

GET /api/v1/tables/{table}

Reads the rows of one table. The three equipment tables are read by tier with part. filter takes a filter segment of the tables page, such as f_burden-2, and keeps the rows the page keeps. 

curl 'https://daggerheart-loot.pages.dev/api/v1/tables/eq_weapon?part=2&filter=f_burden-2'

GET /api/v1/records

Searches the catalog by name, in Russian or in English, and by kind, source, table, tier and rarity. Send q or a facet; limit is 1 to 50. It reads names only. A word that matches too many records answers 400 too_broad: add a longer word or a facet. 

curl 'https://daggerheart-loot.pages.dev/api/v1/records?q=sword&kind=weapon'

GET /api/v1/records/{id}

Reads one catalog record.

curl https://daggerheart-loot.pages.dev/api/v1/records/ci12

GET /api/v1/homebrew-items/{uuid}

Reads one homebrew item whose author shared its link.

curl https://daggerheart-loot.pages.dev/api/v1/homebrew-items/00000000-0000-4000-8000-000000000000

GET /api/v1/shared-lists/{token}

Reads the list behind a share link, as the link's audience sees it. A list whose database answer is larger than 65536 bytes answers 422 with the link of the app. 

curl https://daggerheart-loot.pages.dev/api/v1/shared-lists/SHARE_TOKEN_OF_43_CHARACTERS

POST /api/v1/file-checks

Checks the text of a lists file or a homebrew file as the app's import would, and answers its errors and skips in both languages. The body is the file itself, JSON, at most 32768 bytes. It changes nothing. 

curl -X POST -H 'Content-Type: application/json' --data-binary @lists.json \
  https://daggerheart-loot.pages.dev/api/v1/file-checks

Errors

An error answer is { "format": "daggerheart-loot/api-error", "version": 1, "error": { "code", "message" } }. The message is English and never echoes a value.

Status Code When
400 bad_request A parameter or a body field fails its schema, or a parameter is given twice.
400 too_broad A search matches too many records to rank.
404 not_found An unknown path, section, table, record, homebrew id or share token.
405 method_not_allowed Another method; the Allow header names the allowed ones.
413 too_large A body past 4096 bytes, or a file to check past 32768 bytes.
415 unsupported_media_type A POST body that is not application/json.
422 answer_too_large A database answer past 65536 bytes.
503 unavailable A read failed, timed out or was invalid.

Caching

The lists and the projections carry an ETag and Cache-Control: public, max-age=300, and answer 304 to a matching If-None-Match. Rolls, homebrew items, shared lists and file checks are no-store.

The static catalog mirror

https://daggerheart-loot.pages.dev/api/v1/catalog/index.json lists every record as { id, rev, chunk } with the absolute URLs of the chunk files. The files are static and cost no Functions request.

  1. Read the index. If its data_version equals the one you hold, stop.
  2. Read the chunk of each record whose rev differs from yours. The rev is opaque: compare it for equality only.
  3. Drop each id that the index no longer lists.
  4. If a chunk has another data_version, or a chunk answers 404, the site was updated between your reads: read the index again.

Chunk names and counts are not frozen: follow the index.

Assistants and MCP

llms.txt is the entry for assistants; it also holds the formats of the import files. The operations above, except openapi.json, are also tools of a read-only MCP server at https://daggerheart-loot.pages.dev/mcp; the page for users shows how to connect it.

Account reads

Reads of a signed-in person's own lists and items are planned. Nothing of them is in v1 today.
