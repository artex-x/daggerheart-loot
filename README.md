# Генератор лута для Daggerheart

Двуязычный (RU/EN) генератор добычи для настольной ролевой игры Daggerheart. Статический сайт без сборки: 449 предметов и расходников, у каждого — название, описание и картинка.

**Открыть: https://artex-x.github.io/daggerheart-loot/**

## Возможности

Шесть режимов броска:

| Раздел | Ввод | Результат |
|---|---|---|
| Корник | число 1–60 | Предмет **ИЛИ** Расходник Core |
| Hope & Fear | число 1–60 | Предмет **ИЛИ** Расходник H&F |
| Всё сразу | число 1–60 | 4 варианта: Core предмет/расходник + H&F предмет/расходник |
| Альт. таблицы | редкость + Кость Надежды + Кость Страха | 4 варианта (фильтруется до 2); при крите — полная таблица |
| Wondrous | число 1–119 | 1 предмет |
| Сообщества | сообщество + число 1–10 | 1 предмет |

Плюс:

- **Таблицы** — все таблицы целиком, включая альтернативные, с поиском внутри
- **Поиск** — по всем 449 записям сразу, по названиям и описаниям, на обоих языках
- **Переключение RU/EN** — в любой момент; на каждой карточке есть блок «Показать оригинал» с английским названием и описанием, не выходя из русского интерфейса
- Встроенный бросок костей для каждого режима

## Как отправить предмет в мессенджер

На каждой карточке четыре кнопки:

| Кнопка | Что делает |
|---|---|
| **Отправить** | только на телефоне: системное меню «Поделиться» с картинкой и текстом сразу — в Telegram уходит одним действием |
| **Текст** | название + описание (+ ссылка, если сайт открыт по http) |
| **Картинка** | кладёт саму картинку в буфер обмена, дальше `Ctrl+V` в чат. WebP браузеры в буфер не отдают, поэтому конвертация в PNG идёт через canvas. Если браузер не умеет — картинка просто скачается |
| **Ссылка** | адрес карточки |

Самый короткий путь на десктопе — **Ссылка**. Каждому предмету соответствует статичная страничка `i/<id>.html` с Open Graph разметкой, поэтому Telegram, Discord и прочие разворачивают такую ссылку в карточку с картинкой, названием и описанием — вставил адрес, получил превью.

Странички генерируются скриптом, после правок в `data.js` его надо перезапустить:

```
node tools/build-share-pages.js
```

В `og/` лежат JPEG-копии картинок специально для превью: часть клиентов Telegram не показывает WebP в `og:image`.

## Ссылки на предметы

У каждой карточки есть кнопка **Ссылка**:

```
https://artex-x.github.io/daggerheart-loot/i/ci15.html
```

Ссылка ведёт на статичную страницу с Open Graph разметкой, которая переадресует в приложение. Идентификаторы стабильные и совпадают с `id` в `data.js`:

| Префикс | Что | Пример |
|---|---|---|
| `ci` | Core, предмет | `ci15` — предмет №15 |
| `cc` | Core, расходник | `cc56` |
| `hi` | Hope & Fear, предмет | `hi45` |
| `hc` | Hope & Fear, расходник | `hc60` |
| `w` | Wondrous Loot | `w119` |
| `cm` | Предмет сообщества | `cm81` — первый предмет Wildborne |

Сообщества идут по 10 подряд в алфавитном порядке: Highborne `cm1`–`cm10`, Loreborne `cm11`–`cm20` и так далее.

## Запуск и разработка

Сборки нет, зависимостей нет. Достаточно открыть `index.html` в браузере — работает и с `file://`.

```
index.html                  разметка
style.css                   стили
app.js                      роутинг, режимы бросков, поиск, таблицы
data.js                     данные: window.LOOT
img/*.webp                  449 картинок, 640×640, ~18 МБ
og/*.jpg                    те же картинки в JPEG для превью ссылок, ~20 МБ
i/*.html                    449 страниц-заглушек с Open Graph
tools/build-share-pages.js  генератор i/ из data.js
.nojekyll                   чтобы GitHub Pages не обрабатывал папку через Jekyll
```

## Структура данных

`data.js` — одна строка `window.LOOT = {...}`:

```js
{
  items: {
    core_item: [ { id, src, kind, roll, en, ende, ru, rud, img }, … ],
    core_consumable: [ … ], hnf_item: [ … ], hnf_consumable: [ … ],
    wondrous: [ … ],
    community: [ { …, community, community_ru }, … ]
  },
  alt: {
    item:       { common: { hope: [12 id], fear: [12 id] }, uncommon: {…}, rare: {…}, very_rare: {…}, legendary: {…} },
    consumable: { … }
  }
}
```

| Поле | Значение |
|---|---|
| `en` / `ende` | английские название и описание |
| `ru` / `rud` | русские название и описание |
| `roll` | номер в своей таблице |
| `kind` | `item` или `consumable` |
| `img` | имя файла в `img/`, совпадает с `id` |

Чтобы поправить перевод — меняются `ru` / `rud`. Чтобы убрать предмет — удаляется объект из массива, у остальных пересчитывается `roll`.

## Источники

| Раздел | Записей | Английский текст | Русский текст |
|---|---|---|---|
| Core — предметы | 60 | Daggerheart Core Rulebook (SRD) | [daggerheart.su](https://ru.daggerheart.su/) |
| Core — расходники | 60 | Daggerheart Core Rulebook (SRD) | [daggerheart.su](https://ru.daggerheart.su/) |
| Hope & Fear — предметы | 60 | Daggerheart: Hope & Fear | любительский перевод |
| Hope & Fear — расходники | 60 | Daggerheart: Hope & Fear | любительский перевод |
| Wondrous Loot | 119 | Wondrous Environments | любительский перевод |
| Предметы сообществ | 90 | Community Magic Items | любительский перевод |
| Альтернативные таблицы | 5 редкостей × 4 колонки × 12 | Alternate Loot & Consumable Tables | ссылается на записи выше |

Перевод преимущественно неофициальный. Для терминологии за основу взят [daggerheart.su](https://ru.daggerheart.su/) — поэтому у каждой карточки доступен английский оригинал: если перевод показался странным, оригинал в двух кликах.

Тексты Core приведены с учётом официальной эрраты. Названия предметов везде сведены к написанию из книг.
